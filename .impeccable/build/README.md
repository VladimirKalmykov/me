# Superseded comp build

`superseded-light-comps.json` preserves the unfinished historical state for `index.html`. Its `comps` phase was open and no visual comp was selected. On 2026-10-10 the user changed the design direction to a dark, code-led chronology and explicitly declined image-generated comps. This is an abandoned process record, not a passed gate or a finished site. The current exploratory surface is `prototype/chronology/index.html`; the production routes and PDFs remain future implementation work.
