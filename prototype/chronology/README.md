# Живая хронология — локальный прототип

Запуск из корня репозитория:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Затем открыть `http://127.0.0.1:8765/prototype/chronology/`.

Это сохранённая исследовательская страница. Основной сайт собирается из `templates/portfolio.html` и `content/` в шесть маршрутов; прототип теперь использует те же `css/portfolio.css` и `js/portfolio.js`. Публичные файлы собираются в `dist/`, а исходное `resume.txt` туда не попадает.

Периоды отмечены с точностью до месяца. Чтение и шкала идут от октября 2026 к декабрю 2016; новейший опыт показывается первым. Пробел между подробными подтверждёнными периодами сохранён. Коммерческий опыт с 2010 года указан отдельно и не превращён в выдуманную раннюю хронологию.
